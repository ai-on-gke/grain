# Agent Instructions and Commit Standards

All commits generated by coding and triage agents in this repository MUST strictly follow the Conventional Commits specification.

## Commit Message Format

- `fix:` / `fix(<scope>): <short description>` — Bug fixes, patches, and regressions (eligible for automated RC backports).
- `feat:` / `feat(<scope>): <short description>` — New features or functional enhancements (main branch only).
- `refactor:` / `refactor(<scope>): <short description>` — Code refactoring without behavior change.
- `test:` / `test(<scope>): <short description>` — Adding or updating test suites.
- `chore:` / `chore(<scope>): <short description>` — Build configuration, dependency bumps, or maintenance.
- `docs:` / `docs(<scope>): <short description>` — Documentation updates.

### Structured Footers for Traceability:
- If resolving or referencing an issue: `Fixes: #<id>` or `Issue: #<id>`
- If cherry-picked or backported from another commit/branch: `Backported-from: <commit_sha>`
