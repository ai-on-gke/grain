## §4. Hosted-instance credential hardening, service-account propagation retry and registry walk fixes

## §5. Shell liveness: the disconnected banner on a silent daemon, and phone shell attribute sync

### What changed
- **Disconnected banner on a hung daemon** (`31534b31`, PR #983): `api()` (`ui/src/api.js`) takes an opt-in `timeout: ms` that aborts the whole exchange (body included) and throws an error `isUnreachable()` counts as unreachable, carrying `timedOut`, `timeoutMs` and `sentAt`. Only the main poll's `GET /api/config` passes one: `CONFIG_POLL_TIMEOUT_MS = 10_000` (`ui/src/App.jsx`). The mount load, mutations and other reads keep no timeout. Previously a daemon that accepted the connection and never answered (`kill -STOP`, deadlock, proxy holding the socket) left the page showing stale data as if live.
- **Phone shell sync** (`48034607`, landed with PR #979): `App.jsx` and `AppThemeProvider.jsx` publish `data-phone`, `--sidebar-width` and `data-theme` on `<html>` from `useLayoutEffect` (not `useEffect`), and `useIsPhone()` uses `noSsr: true`, so no frame shows `PhoneNav` with the desktop gutters (the `tasks-load-failed.spec.js` 390 px flake).

### What CI proves
- `api.test.js` (+63: timeout aborts, error shape), `App.resilience.test.jsx` (+60), `ui/e2e/disconnected-banner-silent-daemon.spec.js` (route stalled in Playwright).
- The phone fix is covered by the existing `tasks-load-failed.spec.js` and layout specs.

### What is NOT proved
1. **A really stopped daemon.** Run a real `grain daemon` (or `grain demo`), open `/`, `/tasks`, a task page and a live session in Chromium, then `kill -STOP` the process. The banner must rise within ~10 s plus one poll interval on every page, and data must be marked stale. `kill -CONT`: the banner clears on the next successful poll with no reload, and no duplicate requests pile up (count in-flight `GET /api/config` in the network log during the stop — exactly one at a time).
2. **Other hang shapes.** A TCP proxy (`socat`) in front of the daemon that accepts and never forwards; one that sends headers and stalls the body; a reverse proxy path prefix (the UI served under a sub-path). 3. **Mutations and long reads during a stop.** With the daemon stopped, submit a New task, send a session message, save a Settings field. These have no timeout by design: record what the user sees (spinner forever? error?) and whether the banner explains it. After `CONT`, check each mutation either completed once or failed visibly — never applied twice.
4. **Phone attribute sync in a real browser.** Resize Chromium and WebKit between 1440 and 390 px repeatedly (and rotate 844×390 ↔ 390×844), toggle dark/light, and reload at each width. Assert with bounding boxes that `<html data-phone>` matches `PhoneNav`/sidebar presence on the first painted frame (use `page.evaluate` in a `requestAnimationFrame` after navigation) and that page gutters match.
