## Bugs Found & Resolved

1. **Uncaught Clipboard Exception in Headless Browsers (`ui/src/components/TeamsPanel.jsx`)**:
   - **Symptom**: Calling `handleCopyCommand` in environments without clipboard permissions (e.g. headless Playwright / unprompted iframe) threw an unhandled `NotAllowedError` rejection from `navigator.clipboard.writeText(cmd)`.
   - **Fix**: Added `.catch(() => {})` handler to `navigator.clipboard.writeText(cmd)` in `TeamsPanel.jsx` to gracefully ignore rejection while updating button visual feedback.
