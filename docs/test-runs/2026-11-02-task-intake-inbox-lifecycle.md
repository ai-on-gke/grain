## Observations

- **O1:** with `GET /api/tasks` failing, the Inbox shows the error toast for
  5 s and then only the notifications. It neither claims "Nothing is waiting"
  nor says the list could not be read. A poll that fails with the same message
  does not re-arm the toast's timer (`setError` with an unchanged string), so
  the toast comes and goes in step with the polls.
- **O2:** the task pane's auto-merge switch changes only when the PATCH answers.
  It is not optimistic, as the Edit form's other controls are not either.
- **O3:** list filter and sort edits replace the history entry, by design, so
  Back leaves the list instead of undoing the last filter.
- **11-01 O1 is fixed on `main`:** the stuck group's Undefer sub-case is
  reachable and works (step 6).
- Still true from earlier runs: New task still shows Base branch with No repo
  selected (O5 of 10-29); Pause now asks nothing (O4 of 10-29). A no-repo task's
  pane Repo picker reads "—", with no "No repo" option.
