# Run hosts: a run in a sibling container survives its daemon (2026-10-12)

Task 2990, Stage 2 single-machine of
[`non-disruptive-upgrade.md`](../../design/design/non-disruptive-upgrade.design.md). This records
what was run by hand in the task's sandbox, and what was not.

## What was run

Environment: the grain task sandbox (Debian, docker 29.9.0, Go 1.26.6),
branch `grain/task-2990`.

1. `go test -race -count=3 ./pkg/runhost/`: labels round-trip, N−1
   protocol skew, single-file mounts refused, the docker argv, `docker
   inspect` parsing, the spool cursor (no hole, no duplicate across two
   readers), the entrypoint (output spooled, `env` removed once read,
   exit code and stderr recorded, deadline enforced), the adoption table
   (`TestDecide`), and the restart scenario against a fake driver. Pass.
2. `GRAIN_RUNHOST_DOCKER=1 go test -race -run TestDockerRunHost -v
   ./pkg/runhost/` against the sandbox's real docker daemon with
   `debian:bookworm-slim` and a static `grain` mounted read-only:

   ```
   runhost: starting run host runhost-test-…-runhost-run-7-1-… for run 7-1: /bin/sh -c '… echo "line $i" …'
   runhost: daemon stopping; leaving run host … (run 7-1) running at cursor 21
   --- PASS: TestDockerRunHostSurvivesADaemonRestart (35.32s)
   ```

   The first Host stopped after three lines and detached at cursor 21.
   The container was still listed, with its task, run, protocol and
   deadline labels, while nothing read it. A second Host decided to adopt
   it (gap credited, over one second) and tailed it from cursor 21 to
   line 40. The two transcripts joined to the whole stdout, and the
   container was gone afterwards.
3. `go test ./pkg/orchestrator/ -run 'RecoverRunHosts|RecoverOrphaned'`:
   the startup pass frees an unclaimed run host, finishes a row whose run
   host is gone with the listing's reason, leaves a row that never had a
   run host to `RecoverOrphanedRuns`, and leaves a run host the adoption
   seam takes running. Pass.

The same docker test runs on every branch as the "run host" job in
`.grain/workflows/tests.yml`.

## Stubs

The agent CLI is `/bin/sh` printing numbered lines. No model, no
subscription login and no sandbox VM were involved.

## Not run

The hand run the design asks for, a real agent mid-task on a
subscription login on a real deployment with the daemon restarted under
it, has not been done. It cannot pass yet: the daemon does not detach
from its run hosts when it stops, and an adopted run's outcome and pull
request are not carried into the new daemon. Those are the follow-ups
named in the design's Stage 2 note.
