# v3.3.0

Released 2026-11-09 from commit `545aa3f78`. Changes since `v3.2.0` (`cba7d44bb`):
https://github.com/ai-on-gke/grain/compare/v3.2.0...v3.3.0

## Highlights

**Upgrade notes.** No change in this release needs action on upgrade. Schema migrations rewrite stored grants for you: `github-credential:<name>` becomes `repo#credential` (#812), `read-issues` becomes `github#read-issues` (#769), `github-sandbox` becomes `github#sandbox-repo` (#640), `priority-dispatch`/`durable` move to the task **admission** setting (#814), and `console` moves to the task **hosting** setting (#857). New templates and schedules should use the new names. Permissions are tighter in places: approve and run-now from a limited role now need `tasks:admin` on the task's repository and must stay within that role's ceiling and review template (#965, #987, #1017); run-now's implicit approval needs a reason (#998); and `gma_` tokens whose owner is not on the allowlist are refused (#926, #894).

**Releases and installs**
- Open-source images and version-stamped CLI archives are now published as GitHub release assets instead of GHCR packages (#676, #911). `GET /cli/install.sh` installs the `grain` CLI from a deployment (#901).
- Fixes to the release train: pending-release approvals are stored durably and no longer raised twice (#843, #844), the Inbox lists pending releases under Asked, can approve one with `allow_breaking`, and shows failed promotions (#1025, #1026), and `RELEASE_QUALIFICATION_APP=none` qualifies on Stage 1 alone (#922, #954).
- `grain backup` snapshots PostgreSQL stores with `pg_dump` (#830).

**Usage, access and the UI**
- Grain records token usage for each run and can set budgets per connection (#957).
- `/api/mcp` and `/mcp` check the caller's role on every tool call (#827). Console sessions and API grants record who they act for (#639).
- Closed tasks are searched on the server and load as you scroll (#820), and the task list can be filtered and sorted by admission (#880). The UI walkthroughs also fixed many smaller issues across Settings, the Inbox, boards, sessions and processes.

**Registry (now "Grain Hub" in the UI)**
- Scheduled fleet upgrades, instance stop/start (`grain registry stop|start`), admin recovery tools, two-step transfer, and delegated apps with consent grants (#810, #852, #872, #878, #884). The UI now calls it Grain Hub (#994).
- Tunnel connections are more reliable: a tunnel is handed off during a rolling drain instead of returning 503 (#869), and schema migrations are serialized across replicas (#865).

**CLI and agents**
- New commands: `grain skill install|status` and a local stdio `grain mcp` server (#856). `propose_task` refuses arguments it does not declare (#1020), and a Run now request is used up by the run it starts, even if that run parks (#1029).
