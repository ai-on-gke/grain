# v3.11.0

Released 2026-11-15 from commit `baef865c9`. Changes since `v3.10.0` (`c9c78ed5c`):
https://github.com/ai-on-gke/grain/compare/v3.10.0...v3.11.0

## Highlights

A small release: two fixes to the new Angular UI at `/next/`, found by walking its Settings and Processes pages end to end. Nothing needs action on upgrade, and the classic UI at `/` is unchanged.

**Settings at `/next/`**
- Old links open the right place again: `/admin/...`, `/system/executors`, `/system/integrations`, `/settings/credentials`, `/settings/secrets` and config-repo file links now open the matching Settings page or card instead of the Inbox or Fleet, and `#card` links scroll to their card (#1526).
- Settings → CLI now shows the workstation CLI installer (`/cli/install.sh`, `grain login … --issue-token` and `grain skill install`) instead of the root-only host installer (#1526).
- Settings → Memory's **Save memory** now saves the standing instructions as well as the deployment memory; before, edits to the standing instructions were lost on reload (#1526).
- Access asks before removing any allowlist entry, including your own, and Grant access starts on a role the server accepts. Max agent turns and the follow-up limits are checked by name before saving, Audit shows times in the display time zone, and leaving the page with unsaved changes asks first (#1526).

**Processes at `/next/`**
- Save and preview errors in the schedule, template and suite dialogs are shown in the dialog instead of behind it, and "Every N minutes" accepts the same minimum as the server (#1560).
- Deep links to schedules, templates, suites and suite runs (`/next/schedules/:id`, `/next/templates/:id`, `/next/suites/:id`, `/next/processes/suites/runs/:runId`) open the item instead of the Inbox, and the New menu's links can be reopened after cancelling (#1560).
- Inspecting a template with required fields no longer fails its composition preview, and the preview matches what filing the template sends. Suite runs with no base show "default branch", workflow schedules confirm before **Run now** starts CI, and discovered `.grain/triggers/*` files link to the repository's Advanced settings (#1560).
