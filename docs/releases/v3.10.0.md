# v3.10.0

Released 2026-11-15 from commit `c9c78ed5c`. Changes since `v3.9.0` (`fa4963202`):
https://github.com/ai-on-gke/grain/compare/v3.9.0...v3.10.0

## Highlights

A small release of fixes found walking the 2026-11-13 and 2026-11-15 test plans, plus more of the new UI at `/next/`. If several deployments share one `grain/config`, upgrade the ones that only read it before the ones that write it (see `docs/external-config-repo.md`).

**Schedules, templates and config**
- A deployment reading an external `grain/config` now refuses a dump written by a newer grain on every sync -- its periodic sync, the State pane's Sync and `grain state sync` -- not only at startup, and says so in the State status. Before, an older build could import a newer export and silently drop every template's and schedule's plain reads and writes. Upgrade readers of a shared `grain/config` before writers (#1571).
- A schedule firing a template that names a `sandbox:` size no longer fails setup forever on a host-directory deployment; the template's size is dropped where the backend has none to give. Repository schedules fired by an earlier build get the grants their file declares back on the next reconcile, without waiting for the default branch to move (#1462).
- `grain health` now prints a WARNING naming each base branch whose publishing a release triage task is holding, and the task holding it, instead of printing nothing; it still exits 0 (#1462, #1570).

**Tasks**
- A task whose goal is met while it is running is now closed before dispatch can start another attempt (and another sandbox) for it (#1568).

**The new UI at `/next/`**
- The task page shows path-trigger holds and offers "Defer until…" to park a proposal until a time (#1529).
- `/next/fleet` now shows a warning banner when a base branch's publishing is held by a release triage task ("Publishing held", linking to that task) or has stopped publishing ("Publishing nothing"), and the schedule detail says in words why a schedule is held, names its overlap group, and says whether each skipped occurrence later fired (and as which task) or was dropped (#1578).
- Fixes: Pause takes effect at once, acknowledged alerts leave the Inbox count, re-saving a task's goal keeps its settings, Settings offers the server's sandbox choices and defaults, adding a Git connection over a stored credential keeps a plain git host from becoming GitHub, and the last card in the Agents pane is reachable (#1559, #1487, #1569).
