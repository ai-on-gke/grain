# v1.9.0

Released 2026-10-12 from commit `adea62d8f`. Changes since `v1.8.0` (`0ca8da306`):
https://github.com/bwsalmon/grain/compare/v1.8.0...v1.9.0

## Highlights

- **Teams grow up**: there is a proposer role that can only file tasks as proposals, and a team can make every user a proposer. You can bulk-add members from a pasted list. Each team now has its own Git connections, multi-host repos, a scoped memory layer and credential audit logs (`/api/teams/{id}/audit-logs`). Every team can grant self-debug and pipeline-control to its own work.
- **Git beyond github.com**: the git proxy now supports per-credential hosts, SSH keys and GitHub Apps on GHE, and it can serve plain-git hosts. A `.grain` template can declare which refs its runs push.
- **Remote access through the relay only**: grain-tunnel-gateway is gone (breaking). The rendezvous relay now supports Cloud Run IAP mode with IAP-verified daemon identity, and you can manage it from the UI and from `grain relay`.
- **Day-to-day UI**: there are desktop notifications for new inbox items. You can create a new branch from the New Task form, filter tasks by user, and remove a release and its candidates. System admins act as normal users until they turn Admin mode on, and the Admin section is now called System. `grain version` also shows the version in user settings.
- **CI and ports**: `retrigger_ci` reruns just the failed jobs, and the merge gate combines each job's latest verdict. A port first tries a mechanical cherry-pick before it files an agent task, and main is ported to candidate only for fixes.
- **Security hardening**: a sweep of route authorization fixes. RBAC is now enforced on secrets, releases, force-merge, host logs and repo creation. Other fixes: signed identity assertions replace trusted plaintext headers, packfile and push-body limits in the git proxy, slowloris timeouts on sandboxnet, db-read enforced at the database, and a fix for Go vulnerability GO-2026-6617.
- **Notable fixes**: a repo's task counts and a team's board viewed under another team now show the right tasks. Release images carry their version stamp, and usage-limit pauses are scoped to the connection that owns the credential.
