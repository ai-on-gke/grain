# v1.6.0

Released 2026-10-03 from commit `d49c62ef1`. Changes since `v1.5.0` (`cf9d6156c`):
https://github.com/bwsalmon/grain/compare/v1.5.0...v1.6.0

## Highlights

- **Connections and models are separate.** A connection is how grain reaches a provider and lists the models it can serve. A model is what a team or a task asks for. Runs are round-robined across every enabled connection of the team that serves the chosen model. A task that no connection can serve waits in the queue and says why. Team settings has its own Connections and Models tabs. New task, task edit, bulk edit and the task details show model and connection separately.
- **Templates, schedules and repository declarations can choose a model** (`model:` in `.grain/templates` and `.grain/schedules`). A schedule's choice beats its template's, and nothing chosen means the team's default.
- **Single-day release cycle.** What lands on `main` is cut to `candidate` that night and promoted the next night. A merge onto either paired branch now files a port onto the other, and a task can opt out of porting.
- **`nothing_needed`** lets an agent end a task as needing no work. The task closes by default, or waits for acknowledgement when its template or schedule asks for that.
- **Agent tooling.** `propose_task` can schedule a task for later (`not_before`), and `grain create` / `grain update` can set task dependencies. Teams can set their own merge batch size. Interactive sessions run on macOS. Grain can drive a granule on another machine.
- **Host sandboxes are removed** (breaking). Sandboxes run in granule VMs or containers.
- **A broad security hardening pass.** Proxy and relay tokens are scoped, sealed and expired. Git, model and package-cache egress is narrowed. CSRF, Host, Origin and CSP checks are added. Reads are scoped to the caller's teams. Auto-merge is held on trust-boundary diffs until a security review comes back clean. A two-layer security test suite guards all of this.
- **UI fixes.** Deep links to another team's schedules, templates and suites now open. A link to a missing team says so. Grain asks before Escape or Back drops an edited schedule, template or suite. Phone layouts and keyboard access are fixed across the app.
