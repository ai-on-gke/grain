# v2.1.1

Released 2026-10-22 from commit `3373f533f`. Changes since `v2.1.0` (`19c5923e6`):
https://github.com/ai-on-gke/grain/compare/v2.1.0...v2.1.1

## Highlights

- **A patch release of the page header rail fixes.** `v2.1.1` is `v2.1.0` plus the three
  header-rail commits from `main` (#4387), cherry-picked unchanged with `-x`, and nothing else.
  It is the first patch release, cut by hand as `docs/release-candidate-management.md` ("Patch
  releases") describes.
  - Count badges in the header rail, board columns, inbox groups, dashboard panels and Gantt
    lanes are one badge: the sidebar's count size, tabular numerals, centred on their label.
    Every item in the rail sits on the rail's centre line, where it used to drift up to 22px off
    the title on some pages.
  - Page actions such as "Add repo", Sessions' "+ New session", Processes' "+ New" and a board's
    "Edit board"/"New board" sit at the right-hand end of the rail, just before the global
    buttons, instead of floating mid-rail behind the search box.
  - The Repos discovery caption moves out of the rail into the page body, so the "Add repo" form
    is one row.
- **How this release was qualified.**
  - The pull-request suite (`tests.yml`) passed on the release tree `3373f533f` in run
    `edb8125197e9795a` (task 4984).
  - The release workflow ran on `release/v2.1.1` and published `sha-3373f53` of `grain`,
    `google-grain`, `guest` and `k8s-sandbox`. The `grain` and `google-grain` images carry
    revision label `3373f533f`. `guest` is unchanged from `v2.1.0`. As with earlier releases, the
    images are unsigned: this deployment has no `image-signing` key.
