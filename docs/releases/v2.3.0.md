# v2.3.0

Never released. Candidate `v2.3.0-rc.1` was held at the candidate gate, because the required
nightly kept being cancelled for lack of sandbox capacity, and there is no `v2.3.0` tag. The
same happened to v2.2.0 before it.

Everything v2.3.0 was to carry, including its breaking changes (host mode removed, grain hostd
installed by default, `container`/`host` run locations, ports in 42xx), shipped first in
**v2.4.0**. See [v2.4.0.md](v2.4.0.md), which covers everything since `v2.1.1`.
