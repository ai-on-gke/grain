# v3.12.0

Released 2026-11-17 from commit `e06c55510`. Changes since `v3.11.0` (`baef865c9`):
https://github.com/ai-on-gke/grain/compare/v3.11.0...v3.12.0

## Highlights

Nothing needs action on upgrade. The schema migrations this release adds run on their own when the daemon starts, and the classic UI at `/` keeps working beside the new one at `/next/`.

**The new UI at `/next/` reaches classic parity in Settings**
- Settings → Hosts, Git, Hub, Sandboxes, Engine, CI and Capabilities (secrets, scope sets and credentials) now do what their classic pages do. Settings → Hosts shows the Invite hosts command, and Settings → Repositories gains Declarations and Git connection columns (#1596, #1613, #1640, #1611, #1614, #1589).
- There is a new `/next/repos` list. A repository's page shows work ownership, its qualification plan, CI capabilities and import interval, and warns when nothing judges its base branch (#1599, #1595, #1592).
- `/next/tasks` gets classic's batch actions and **Run selected now**. Processes can be sorted and custom-ordered, and Markdown everywhere, the Context page's previews included, draws Mermaid diagrams inline (#1584, #1603, #1610, #1668).

**Faster pages behind a slow identity proxy**
- `/next/` pages now fetch task summaries in one batched request (`GET /api/tasks/summaries`) instead of one request per task. `GET /api/tasks` reads only the open tasks it returns, not the whole history (#1542).
- Content-hashed frontend bundles are served without identity verification and are cached as immutable. An IdentityVerifier that has to call a remote service can bind a short signed session (at most 5 minutes), so it no longer turns page loads into `503 verifier_unavailable` (#1574, #1612, #1626).

**Reviews, goals and usage**
- When a review's findings block a merge, a person can now accept the findings, with a reason, instead of force-merging. In the new UI this is **Accept findings…** on the Changes tab; on the command line it is `grain accept-findings` (#1292).
- Autonomous Goal Mode is a new opt-in posture beside Supervised tasks. Only `tasks:admin` can enable it. It tracks assumptions and a deliverable scorecard and runs a bounded multi-pass verifier (#1690). The Software Workflow & QA Studio (`qa-flow/v4`) is now in Processes and Telemetry (#1698).
- Usage reports the weekly limit beside the interval window, with a run-out warning. A paused model's reset is shown on the local clock with the time zone named (#1604, #1606).
- A Codex connection can use its own ChatGPT subscription login (`auth.json`), and **Test connection** is back in the new UI's model settings (#1587, #1646).

**Fixes worth knowing**
- Tasks waiting in `resume_later` now get the review threads and review decisions posted on their pull request (#1590).
- `grain ci log --job` and `ci://` can read CI jobs whose names contain a `/` (#1622).
- A hand-written template in `grain/config` that leaves out `target:`, `auto-merge:` or `created-at:` now imports, instead of failing with a NOT NULL error (#1648).
- `propose_task` refuses a retired bare capability name and says what it became (#1588).
