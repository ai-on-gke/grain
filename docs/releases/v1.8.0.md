# v1.8.0

Released 2026-10-11 from commit `0ca8da306`. Changes since `v1.7.0` (`a9469b26f`):
https://github.com/bwsalmon/grain/compare/v1.7.0...v1.8.0

## Highlights

- **Connections and models are separate.** A model now round-robins across every connection that serves it. Connections advertise every model their provider lists, and a task says where its model came from.
- **Multiple git hosts.** The git proxy routes per host and supports GitHub Apps on GHE, plain-git hosts and SSH keys. Teams manage their own Git connections and multi-host repos in team settings.
- **Merge queue path rules.** `.grain/merge-rules.yml` sets batching, repairs, flake rechecks and porting per path. Ports try a mechanical cherry-pick before filing an agent task.
- **Faster CI recovery.** `retrigger_ci` reruns only the failed jobs, and the merge gate combines each job's latest verdict, so a green recheck clears a flake without rerunning the full suite.
- **Rendezvous relay.** The relay replaces the tunnel gateway for remote access. It supports Cloud Run IAP mode and is managed from the UI or `grain relay`.
- **Teams and admin.** New proposer role, bulk-add of team members, team-scoped memory, and capabilities in declarations bounded by team authorization. System admins act as normal users until Admin mode is turned on.
- **Signed upgrades.** Image publishers are verified before an upgrade runs, upgrades drain without disruption, and `grain version` is new.
- **UI.** Desktop notifications for the inbox, a task-rooted work tree, pull requests waiting on GitHub approval in the inbox, and removing a release with its candidates.
- **Security fixes.** Signed identity assertions replace plaintext headers. Packfile and push-body parsing are bounded in the git proxy, and mutating secret endpoints are admin-only.
