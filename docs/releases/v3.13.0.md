# v3.13.0

Released 2026-11-17 from commit `46fdc1104`. Changes since `v3.12.0` (`e06c55510`):
https://github.com/ai-on-gke/grain/compare/v3.12.0...v3.13.0

## Highlights

v3.13.0 is a small release with no breaking changes: nothing needs action on upgrade. Most of it fixes the `/next/` UI, task list performance and the host updater.

- **Processes on `/next/` matches the classic forms.** The schedule and template dialogs now set Admission (standard, bypass queue, durable), Hosting (unattended or interactive console), Keep running, Grants and a searchable Model picker. The grants picker flags any grant the capability policy would refuse. The selected schedule, template, suite or suite run is now kept in the URL, so reload, copied links and Back/Forward all land on the same item.
- **Faster, correct task lists on large deployments.** `GET /api/tasks/summaries` no longer rebuilds every task on each quiet poll, and polls no longer push open task panes out of the cache. Before this fix, polling 5,000 tasks took hundreds of milliseconds per request. Filtered task lists now show the right queued reason as soon as a dispatch condition changes. On `/next/`, a single failed batch no longer blanks the summaries that did load.
- **Inbox notes on `/next/`.** A task resting on a summarized closing note now shows a neutral "Note" pill and the note's own line, instead of "Needs reply".
- **Config repository errors are visible.** On `/next/` Settings → Config repository, a sync refused because of a newer schema now shows up, as does a failed Sync now.
- **Hosts.** On `/next/` Settings → Hosts, the `grain-agentd` update command now has a Copy button, and the hosts table stacks cleanly on a phone. A downloaded `grain-agentd` that fails its smoke test is no longer left behind under `versions/`.
- **Repair tasks and CI.** An open repair task now gets CI access on its next red run. It is only told that CI reads are denied when the grants it holds really cannot read CI.
- **Chat gateway.** `grain-plc`'s chat gateway now delivers to an `-outbound-url`. A slow or failing chat platform costs only that one message, and the failure is logged; the stream carries on.
- **Images.** Sandbox guest images now pick up current Debian security updates when they are built.
- A blank task detail pane that sometimes appeared when switching tasks on `/next/` is fixed.
